# Sistema de Recuperação de Informações com LangChain e FAISS

Este projeto implementa um sistema de recuperação de informações utilizando vetores de embeddings e banco de dados vetorial, integrado à biblioteca LangChain.

## Dependências
- Python 3.8+
- langchain
- faiss-cpu
- beautifulsoup4
- requests
- ollama-sdk
